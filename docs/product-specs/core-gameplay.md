# Spec: Core Gameplay
Status: Ready · Phase 2

> 영감: 플래시 시절 탑다운 좀비 서바이벌(박스헤드류)의 "좁은 맵, 몰려오는 떼, 콤보로 무기 해금" 루프.
> 이름·그래픽·맵·수치는 **자체 제작**. 레퍼런스 게임의 에셋/레이아웃 복제 금지.

## 코어 루프 (한 판 10~20분)
`웨이브 시작 → 떼 처치 → 콤보로 점수 배율↑ → 점수 임계 도달 시 새 무기/설치물 해금(팀 공유) → 인터미션 8초 → 다음 웨이브(더 많고 빠르게)`
전원 다운 → 게임오버 → 결과(도달 웨이브, 팀 점수, 개인 킬/부활 기여)

## 월드
- 맵: 32×24 타일 가시 영역, 전체 최대 64×64. 1타일 = 32px 렌더
- 스폰 포인트: 맵 가장자리 문 4~8곳. **어떤 플레이어 시야(카메라 사각형)에도 들어있지 않은** 곳만 활성
- MVP 맵 1개(`yard`): 중앙 광장 + 좁은 통로 3 + 파괴 불가 벽

## 플레이어
| 항목 | 값 |
|---|---|
| 이동 | 8방향, 속도 0.09 타일/프레임 (5.4 타일/초) |
| 조준 | 마지막 이동 방향 = 조준 방향. 조준고정(Shift) 누르면 facing 유지하며 이동(뒷걸음 사격) |
| 체력 | 100. 초당 자연회복 없음, 픽업 회복 +30 |
| 충돌 반경 | 0.35 타일 |
| 아군 사격 | **없음** (MVP). 폭발은 아군 무피해 |
| 다운 | HP 0 → 다운 상태 10초(기어서 0.02 타일/프레임 이동 가능) → 아군이 인접(1타일) 2초 유지 시 HP 40으로 부활, 10초 경과 시 사망(다음 웨이브 시작 시 HP 50으로 부활) |
| 1인 플레이 | 다운 = 즉시 게임오버 |

## 콤보 & 점수
- 처치 시 `combo += 1`, 2초(120프레임) 내 추가 처치 없으면 0으로 리셋
- 점수 = 적 기본점수 × (1 + min(combo, 50) × 0.1)
- **해금은 팀 점수 합계 기준**, 해금 무기는 전원에게 지급 (협동 유도, 킬 스틸 동기 제거)

## 웨이브
- 적 수 = `8 + wave × 4 × present_players^0.7` (정수 LUT), 동시 생존 상한 = MAX_ENEMIES(384)
- 속도 배율 = 1 + min(wave, 20) × 0.02
- 5웨이브마다 엘리트(Brute) 등장. 적 조성은 [weapons-and-enemies.md](weapons-and-enemies.md)

## 이탈 플레이어
present=0 → 180프레임 후 캐릭터 제거, 난이도는 남은 present 수로 **다음 스폰부터** 재계산

## 수용 기준
- [ ] AC1 2인 세션에서 한 명이 60초 이동/사격 중 **상대 화면에서 위치 차이 ≤ 0.5타일(롤백 보정 후 10프레임 이내 수렴)** — netsim RTT 100ms
- [ ] AC2 적 384 + 투사체 512 동시 상황에서 sim step p99 ≤ 0.6ms (wasm, [QUALITY_SCORE.md](../QUALITY_SCORE.md))
- [ ] AC3 좀비가 벽 모서리·좁은 통로에서 5초 이상 끼지 않음 (시나리오 테스트 `stuck_detection`: 10분 시뮬 중 이동량 0인 적 5초 이상 = 실패)
- [ ] AC4 스폰은 항상 모든 플레이어 카메라 밖 (속성 테스트)
- [ ] AC5 부활·다운·게임오버 전이 상태머신 표 전 경로 단위 테스트
- [ ] AC6 같은 시드+입력 로그 재생 시 점수·웨이브·킬 수 동일 (insta 스냅샷)
- [ ] AC7 이탈 후에도 남은 인원 게임 계속, 난이도 재계산 반영
