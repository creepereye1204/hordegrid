# Spec: New User Onboarding
Status: Ready · Phase 1–2

## 목표
처음 온 사람이 **가입·설치·설명 없이** 친구와 같은 판에서 좀비를 쏘기까지 **30초 이내**(친구가 이미 방에 있을 때).

## 사용자 흐름
### A. 방 만드는 사람
1. `https://<user>.github.io/hordegrid/` 접속 → 타이틀 화면: **[방 만들기] [코드로 참가] [혼자 연습]**
2. [방 만들기] → 즉시 로비. 큰 글씨 초대코드 `4821 0937` + **[링크 복사]** + QR + [코드 재발급]
3. 닉네임은 자동 생성(`좀비사냥꾼-42` 류), 클릭해서 변경. 로컬에만 저장
4. 친구가 들어오면 방장에게 **입장 요청 토스트 [수락] [거절]** → 수락 시 슬롯에 표시(색상·닉·핑 ms). 전원 [준비] → 3초 카운트다운 → 시작

### B. 링크 받은 사람
1. 링크 열기 → 로딩(wasm) → **곧바로 해당 로비** (타이틀 건너뜀)
2. "방장 승인 대기 중" → 승인되면 [준비] 누르면 끝

### B'. 코드를 불러받은 사람
타이틀 [코드로 참가] → 숫자 키패드로 8자리 입력(4자리 후 자동 공백, 붙여넣기 시 숫자만 추출) → B-2와 동일

### C. 혼자 연습
`LoopbackTransport` 1인 세션. 네트워크 코드 경로는 동일(GGRS 1인 + 로컬)이라 QA 대체 불가 영역 없음

## 조작 안내
- 첫 게임 첫 10초 동안 화면 하단 반투명 키 안내: `WASD 이동 · Space 발사 · Q/E 무기 · F 설치 · Shift 조준고정`
- 게임패드 연결 시 안내가 패드 아이콘으로 바뀜. 터치 기기는 가상 스틱 2개 [FRONTEND.md](../FRONTEND.md#입력)

## 수용 기준
- [ ] AC1 링크 → 로비 표시까지 **p75 ≤ 3초** (4G 프로파일, 캐시 없음). 측정: Lighthouse/Playwright 네트워크 스로틀
- [ ] AC2 두 피어가 같은 초대코드로 들어오면 **p75 ≤ 8초** 내 로비에 서로 표시 (실네트워크 수동 20회 중 15회)
- [ ] AC3 5번째 입장자는 "방이 가득 참" 화면, 기존 4명에게 영향 없음
- [ ] AC4 buildHash 다르면 양쪽에 "버전 다름 — 새로고침" 표시, 게임 시작 버튼 비활성
- [ ] AC5 직접 연결 실패 시 8초 내 원인 안내 문구 + [다른 방법] 버튼 (수동 연결). 무한 스피너 금지
- [ ] AC6 새로고침/뒤로가기 후 같은 링크로 로비 재입장 가능 (게임 시작 전)
- [ ] AC7 모든 로비 문구 한국어 기본 + 영어 (`navigator.language`)
- [ ] AC8 방 만들기 → 링크 복사 과정에서 클립보드 권한 실패 시 코드 텍스트 선택 폴백
- [ ] AC9 방장이 수락하기 전 피어는 로비 목록·ready·게임 시작 대상에 **포함되지 않음** (단위 테스트: 로비 상태머신)
- [ ] AC10 20초 무응답 = 거절 처리, 거절된 사람에게 문구 표시
- [ ] AC11 게임 시작 후 같은 코드로 접속하면 "진행 중이거나 없는 방" 안내 (대기 30초 후)
- [ ] AC12 코드 입력칸은 모바일에서 숫자 키패드, `4821-0937`/`4821 0937` 붙여넣기 허용
