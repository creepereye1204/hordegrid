# Spec: Weapons, Placeables & Enemies
Status: Draft · Phase 2–3

모든 수치는 `crates/sim/src/tables.rs` 상수 테이블(Flyweight)이 원본. 이 문서와 다르면 **이 문서를 먼저 고친 뒤** 테이블 반영.
단위: 거리 = 타일, 시간 = 프레임(60=1초), 데미지 = HP.
