## Internals that matter to us (from peer.mjs 0.25.4)
- trystero's own channel: pc.createDataChannel("data") — NON-negotiated, default reliable+ordered, created by initiator
- our game channel: pc.createDataChannel('ggrs', { negotiated: true, id: 101, ordered: false, maxRetransmits: 0 })
  created on BOTH sides inside onPeerJoin -> opened in ~10ms in Chromium E2E. No collision observed.
- onPeerJoin fires only after trystero's channel is open => failed ICE never surfaces as an event (no "peer seen but failed").
- getRelaySockets(): Record<url, WebSocket> -> count readyState===1 for relay health UI
