# DESIGN (시각·UX 디자인 시스템)

## 톤
"80년대 B급 호러 VHS × 픽셀 아케이드". 어둡지만 **가독성 우선** — 떼 속에서 내 캐릭터·탄·위험이 0.2초 안에 구분돼야 한다.

## 색 토큰 (`web/src/ui/tokens.css`, 렌더러도 같은 값 import)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#0e0f13` | 바닥 기본 |
| `--floor-alt` | `#171922` | 타일 체커 |
| `--wall` | `#3a3f4f` | 벽 |
| `--p1..p4` | `#4fd1ff` `#ffcf3f` `#ff5fa2` `#7dff6a` | 플레이어 — 색각이상 시뮬(Deuteranopia/Protanopia)에서 상호 구분 확인 필수 |
| `--enemy` | `#9aa37a` | 일반 적 (채도 낮춤 → 플레이어가 튐) |
| `--elite` | `#d9480f` | Brute |
| `--danger` | `#ff3b3b` | 적 투사체, 폭발 예고 |
| `--ui-fg` / `--ui-dim` | `#f1f1f1` / `#8a8f9c` | HUD |
- 플레이어 색은 **색만으로 구분하지 않는다**: 머리 위 번호(1~4) + 발밑 링

## 타이포
- HUD 숫자: `"Press Start 2P"`(Google Fonts, OFL) 12/16px 정수 배율만
- 한국어 UI 본문: `"Galmuri11"`(OFL, 자체 호스팅 `public/fonts`) — 픽셀톤 유지
- 최소 크기 12px @1x, 모바일은 1.5배

## 레이아웃
- 캔버스는 정수 배율 스케일(1x/2x/3x) + 레터박스, `image-rendering: pixelated`
- HUD: 좌상 팀 점수·웨이브 / 우상 콤보 / 하단 중앙 무기 슬롯·탄약 / 플레이어별 HP는 캐릭터 머리 위 바
- 로비: 모바일 세로 기준 1열, 16px 거터, 가로 스크롤 금지
- 게임: 가로 전용. 터치 버튼은 반투명(`--ui-fg` 18% 알파), 누르는 동안 40%. 레이아웃·크기는 [mobile-play.md](product-specs/mobile-play.md)

## 모션 & 피드백 (sim 이벤트 기반)
| 이벤트 | 시각 | 소리 |
|---|---|---|
| Hit | 적 1프레임 흰색 플래시 | 짧은 틱 (동시 최대 6채널) |
| Kill | 파편 4~8개(렌더 전용 파티클, 롤백 무관) | 퍽 |
| Combo 10/25/50 | 우상단 숫자 스케일 펄스 | 상승음 |
| Unlock | 화면 상단 배너 1.5초 | 팡파레 |
| Down | 화면 가장자리 붉은 비네트(본인), 아군 위치 화살표 | 경고음 |
- 화면 흔들림은 설정에서 끌 수 있어야 함 (기본 약하게)
- `prefers-reduced-motion` → 흔들림·펄스 0

## 에셋 규칙
전부 자체 제작 또는 CC0/OFL (출처는 `web/public/assets/CREDITS.md`). 스프라이트 16×16 기본, 아틀라스 1장 ≤ 1024².
